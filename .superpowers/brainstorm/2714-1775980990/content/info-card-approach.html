Strain Info Card — How should it appear?

When a user taps a strain in the browse list, which presentation feels right for the app?

A

Bottom Sheet

A panel slides up from the bottom, covering ~70% of the screen. Feels native on mobile — familiar swipe-down to dismiss. Great for scanning info without fully losing context of the list behind it.

📱 Most mobile-native feel · Swipe to dismiss · Partial context preserved
B

Full Modal Overlay

A centered modal dialog (matching the existing custom/override modals). Same interaction pattern already in the app — tap backdrop to dismiss. Focused, no distraction, consistent with existing UI.

🎯 Consistent with existing modals · Centered · Tap backdrop to close
C

Inline Expansion

The strain card expands in-place to reveal the full info — description, flavors, rating. No overlay needed. Fast and lightweight, but can feel cramped on smaller screens with many strains in the list.

⚡ No overlay needed · Stays in list context · Less visual drama
